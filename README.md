# Task Grid

A React + TypeScript + Vite application for managing tasks in a grid layout.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Lemonszz/task-grid.git
cd task-grid
npm install
```

## Development

Run the development server:

```bash
npm run dev
```

This will start the Vite development server. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:5173`).

### Cachine Task Icons
```bash
npm run download-images
```
This will go through all the tasks, downloading and caching their icons from external sources if the file doesn't exist.


## Building for Production

Create a production build:

```bash
npm run build
```

The built files will be output to the `dist` directory.
